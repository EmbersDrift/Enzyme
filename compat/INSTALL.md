# Enzyme 0.4.0：五个 Fabric 版本安装说明

安装包中的五个 JAR 分别对应五个 Minecraft 版本。每个实例只选对应的一个 JAR，放入 mods，并移除旧版 Enzyme。不要把五个 JAR 一起安装。

| Minecraft | 安装文件 | 游戏 Java | 本次验证的 Fabric API |
| --- | --- | --- | --- |
| 1.18.1 | enzyme-1.18.1-0.4.0.jar | 17 | 0.46.6+1.18 |
| 1.20.1 | enzyme-1.20.1-0.4.0.jar | 17 | 0.92.12+1.20.1 |
| 1.20.6 | enzyme-1.20.6-0.4.0.jar | 21 | 0.100.8+1.20.6 |
| 1.21.8 | enzyme-1.21.8-0.4.0.jar | 21 | 0.136.1+1.21.8 |
| 1.21.11 | enzyme-1.21.11-0.4.0.jar | 21 | 0.141.6+1.21.11 |

使用 Fabric Loader 0.19.5 和对应游戏版本的 Fabric API；Fabric API 需要另行安装。1.18.1 请使用 [Fabric 官方完整安装包](https://github.com/FabricMC/fabric-api/releases/tag/0.46.6%2B1.18)，不要使用只有模块声明的 Maven 小文件。

当前交付内置 Windows x64 转换程序，核心保持 0.2.2。旧版采用兼容背景，转换选项、报告、历史等操作一致。

五个版本均经过编译、真实执行器升降级、开发客户端和交付 JAR 的正式 Fabric 启动与鼠标操作检查。verification.json 记录对应文件 SHA256 与测试路径。自动测试使用合成资源包，实际材质效果和第三方 MOD 共存还需实机确认。

打开“选项 → 资源包”，首次会检测一次，后续使用“检查资源包版本”。输出不自动启用；带警告时原包保留，先查看效果再在历史中归档。建议先复制资源包到测试实例，优先观察物品、方块、热键栏、背包、创造栏和字体，并分别测试旧包升级与新包降级。

发现问题时保留游戏 logs/latest.log、报告详情导出的诊断 ZIP、操作步骤、其他 MOD 列表及效果截图。详细清单见随包 TESTING.md。
